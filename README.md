# Лабораторна робота 5

Тема: Django-форми, валідація даних, моделі, SQLite та CRUD-операції.

Предметна область: інформаційна система обліку паливно-мастильних матеріалів.

## Що реалізовано

- створено моделі `FuelType`, `FuelItem`, `IssueRecord`;
- створено модель `User` з ролями `admin` та `user`;
- налаштовано SQLite у `fuel_project/settings.py`;
- створено міграції та початкові дані;
- додано форми Django у `app/forms.py`;
- реалізовано CRUD з урахуванням ролей користувача;
- під час видачі ПММ перевіряється, що обсяг не більший за залишок на складі.

## Демо-користувачі

- `admin / admin123` - адміністратор, може додавати, редагувати та видаляти типи ПММ, ПММ і записи журналу;
- `operator / user123` - оператор, може переглядати дані та оформлювати видачу ПММ.

## Сторінки

- `/` - головна сторінка;
- `/login/` - вхід у систему;
- `/sqlite/` - інформація про SQLite та моделі;
- `/fuels/` - список ПММ;
- `/fuels/create/` - додавання ПММ;
- `/fuels/1/` - детальна сторінка ПММ;
- `/fuels/1/edit/` - редагування ПММ;
- `/fuels/1/delete/` - видалення ПММ;
- `/fuel-types/` - типи ПММ;
- `/fuel-types/create/` - додавання типу;
- `/issues/` - журнал операцій;
- `/issues/create/` - додавання операції видачі.

## Запуск

```bash
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Після запуску сайт буде доступний за адресою:

```text
http://127.0.0.1:8000/
```
